# Security policy

SynthOCR is a local tool: the app listens only on `127.0.0.1` and has no login.
Do not expose it directly to the internet; see the [hosting guide](docs/hosting.md).

## Reporting a vulnerability

Please report security problems privately through
[GitHub's private vulnerability reporting](https://github.com/ardalan-jalal/SynthOCR/security/advisories/new),
not in a public issue. Include the steps to reproduce and the version you used.
You can expect a reply within a week.

## Supported versions

Security fixes are made on the latest release on the `main` branch.
